# Данные и приватность

«Лист» хранит библиотеку локально и подключается к ИИ через официальный Codex CLI, когда вы запрашиваете ответ или практику. Репозиторий содержит исходники, оригинальное руководство, тесты и демонстрационные скриншоты. Личных книг, переписки, решений и авторизации автора в нём нет.

## Локальное хранение

Публичная версия использует папку:

```text
~/Library/Application Support/ReaderForEngineers/
```

В ней находятся:

| Данные | Назначение |
| --- | --- |
| `library.json` | Метаданные книг, порядок, архив и место чтения |
| `Books/` | Импортированные копии книг, разобранный текст и локальный поисковый кеш |
| `conversations.json` | Переписка по книгам |
| `practice.json` | Задания, код, вывод и разборы практики |

Оформление и некоторые настройки окна хранятся в настройках macOS для приложения `com.readerforengineers.ListReader`. Учётные данные ChatGPT в этих файлах не сохраняются.

Импорт копирует исходный файл. Удаление книги через библиотеку перемещает её копию из `Books` в Корзину; исходный файл не изменяется. Историю чата можно очистить в панели помощника. Само удаление книги не следует считать гарантированным удалением всех связанных записей из истории и практики.

Для резервной копии завершите приложение через **⌘Q**, затем скопируйте всю папку `ReaderForEngineers` в своё защищённое хранилище. Для восстановления при закрытом приложении верните папку на прежнее место. В ней могут находиться полные книги и личные заметки: не добавляйте эту папку в публичный Git-репозиторий.

## Что получает ИИ

Когда вы отправляете вопрос, приложение передаёт через Codex:

- вопрос и ограниченную часть предыдущей переписки по текущей книге;
- название, автора, главу, местоположение и ваше краткое описание книги;
- извлечённый текст текущей страницы или видимого места и выделенный фрагмент;
- дополнительные выдержки, если помощник запросил поиск по главе или прочитанной части книги.

Поиск выполняет само приложение локально. Сначала доступна текущая глава целиком, включая страницы после вашего места. Затем можно искать по книге до зафиксированной позиции чтения. Номер страницы не позволяет модели расширить эту границу. Объём выдержек ограничен; большой раздел может попасть в запрос частично.

При создании практики передаётся выбранный материал. При подсказке и проверке также могут передаваться задание, ваше решение, вывод запуска и предыдущий разбор. Кнопка запуска кода сама по себе не отправляет решение ИИ.

Обычное перелистывание, импорт и чтение не требуют отправки текста книги в сервис ИИ. У приложения нет собственного сервера для библиотеки или синхронизации. Обработка данных, переданных OpenAI, определяется настройками вашего аккаунта и [политикой OpenAI](https://openai.com/policies/privacy-policy/).

## Авторизация

Официальный Codex CLI открывает браузерный вход и сам управляет своими учётными данными. Приложение проверяет статус через `codex login status`; токены и пароль не читает и не копирует. В этой версии используется вход через ChatGPT. Подробности: [официальная документация по авторизации](https://learn.chatgpt.com/docs/auth).

Для ответов CLI запускается в отдельной временной рабочей папке с отключёнными инструментами shell, браузером, внешними коннекторами и чтением проектных инструкций. Это ограничивает помощника предоставленным текстом и локальным поиском приложения. Данные книги рассматриваются как материал для чтения, а не команды к выполнению. Временная папка запроса удаляется после завершения; собственное хранение и диагностика CLI регулируются самим CLI.

## Выполнение кода

Практика использует локальный Docker. При подготовке образ скачивается из реестра. Сам учебный контейнер запускается без сети, от непривилегированного пользователя, с файловой системой только для чтения и отдельными временными каталогами. Папки Mac и сокет Docker внутрь не подключаются. Действуют ограничения времени, CPU, памяти, числа процессов и вывода.

Код приходит через стандартный ввод. После выполнения или остановки контейнер удаляется. Образы Docker остаются в локальном кеше Docker; управлять ими можно через Docker Desktop. Среда рассчитана на небольшие учебные задачи и не заменяет отдельную среду для полноценного проекта.

## Скриншоты и публикация

Публичные изображения сняты в отдельной демонстрационной библиотеке. Они показывают страницы книги Мартина Клеппмана «Высоконагруженные приложения» и заново выполненные примеры работы приложения. Файл книги не входит в репозиторий, архив приложения или исходников. Права на текст книги принадлежат соответствующим правообладателям; лицензия MIT проекта относится к исходному коду приложения.

При подготовке своих скриншотов проверяйте имена файлов, переписку, текст кода и соседние окна. Для изолированного тестового профиля предусмотрена переменная `READER_DATA_DIR`; [пример запуска](DEVELOPMENT.md).
